# Cryptocurrency Advisor Chatbot

A rule-based AI chatbot that provides cryptocurrency investment advice based on profitability and sustainability metrics.

## Features
- 💰 **Profitability Analysis**: Recommends coins with rising price trends
- 🌱 **Sustainability Focus**: Prioritizes eco-friendly cryptocurrencies  
- 💬 **Interactive Chat**: Simple conversational interface
- 📊 **Data-Driven**: Uses predefined crypto metrics for recommendations

## Technologies Used
- Python 3.x
- Rule-based AI logic
- Dictionary-based data storage

```bash
# Clone repository
git clone https://github.com/YASIN-Y15/crypto-advisor-chatbot.git

# Run chatbot
